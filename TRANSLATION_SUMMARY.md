## 🔍 What's NOT Translated

**Frontend UI Text:**
The frontend application uses a translation system (`useLanguage()` hook) that allows for multiple languages. The UI strings are managed separately through translation keys like:
- `t('dashboard.title')`
- `t('vehicles.add')`
- etc.

These can be configured in the language provider component to support French, English, or any other language.
